The server behind this page

Since 2019 I've run a small home server, now a Raspberry Pi 5 on Debian. It hosts the services I use every day and is the place where I learn system administration by doing it. This is how traffic reaches it.

Things I set up and maintain

  • Remote administration only through the VPN, so SSH never faces the internet.
  • Anubis in front of public instances, so automated scrapers must solve a proof-of-work challenge before they reach it.
  • Network-wide DNS filtering for every device connected to the VPN.
  • A Minecraft server for friends, run as a systemd service with backups every six hours and rotation. Other people reach its files through SFTP in a chroot jail with TOTP two-factor login.
  • A self-hosted Git server (Forgejo) where my configuration files and projects live.
